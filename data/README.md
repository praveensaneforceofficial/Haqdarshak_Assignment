# Data Directory for Haqdarshak Scheme Extraction

This directory contains synthetic test documents representing real-world scheme notifications:
1. `doc_1_english_circular.txt`: State government circular in English (Mukhyamantri Balika Protsahan Yojana).
2. `doc_2_hindi_circular.txt`: State government circular in Hindi (Devanagari script) (Kisan Samman Nidhi).
3. `doc_3_myscheme_portal_conflict.txt`: MyScheme portal listing that contradicts doc_1 on benefit amount and application deadline.
4. `doc_4_scanned_noisy_ocr.txt`: Synthetic OCR-extracted text simulating character artifacts and broken line breaks.
